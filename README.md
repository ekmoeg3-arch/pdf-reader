# PDF Reader

A small offline Android PDF reader with no ads or account.

[Download the APK](https://github.com/ekmoeg3-arch/pdf-reader/releases/latest/download/PDF-Reader-1.0.1.apk)

Requires Android 9 or newer. Download the APK on your phone and open it with your browser or Samsung My Files. Allow installation from that app if prompted. Existing users can install version 1.0.1 over the previous version without uninstalling.

This repository hosts signed APK downloads. The source project and signing key remain local.

Version 1.0.1 addresses the PDF-opening failure by replacing the Android 9-14 reader. Build and signature checks passed, but the fix still needs confirmation on a real phone. If the app closes, reopen it and tap Copy report. If an error dialog appears, tap Copy error.
